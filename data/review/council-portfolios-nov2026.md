# Council Portfolio Review — November 16, 2026

Source: Mayor Daniel Fontaine's portfolio letters to the six councillors
(`newwestcity.ca/city-hall/mayor-councillors/mayors-office`), dated 2026-11-16.

Each letter has four parts: (1) committee/board assignments, (2) neighbourhood
liaison assignments, (3) the councillor's "signature project(s)", and (4) a
"Mayor's priority project". This file maps those goals/tasks to existing tracked
promises, and flags items that don't match anything for review.

Key for the mapping below:
- `→ "Exact promise title"` = maps to an existing tracked promise.
- `→ (partial) "…"` = overlaps an existing promise but is narrower/newer.
- `→ [NEW]` = no matching promise — candidate for a new tracked promise.
- `→ [structure]` = a committee/board appointment, not a campaign promise.

## Items to decide on (for new/updated promises)

1. **[NEW] Folka — Downtown–Quayside Community Hub.** Reimagining ~50% of the Fraser River Discovery Centre building as a multi-purpose community facility. No existing promise covers a new community hub at this site. → propose a new promise, champion: Folka.

2. **[NEW] Budhwani — Belmont Square & Uptown (Sixth Street) revitalization.** Uptown corridor (not Downtown/Columbia). No existing promise. → propose a new promise, champion: Budhwani.

3. **[Partial] Armstrong — additional artificial turf field.** The tracked promise is "Ensure existing sports fields can be used year-round, while pursuing new fields"; the letter specifies "at least one additional turf field beyond Ryall Park". Consider a distinct goal/metric.

4. **[Partial] Armstrong — EV charging in Queensborough.** "Lead by example" is broad; the letter narrows it to a Queensborough-specific EV-charging build-out. Consider a distinct goal/metric.

5. **[Partial] Henderson — new Downtown public library.** Currently only a sub-item of "Make our cultural facilities more accessible". Arguably worth its own promise (shovel-ready by 2030).

6. **[Partial] Henderson — supportive housing.** "Support housing with compassion and common sense" is broad; the letter sets a specific target (secure funding + commence construction of a supportive-housing project). Consider a goal/metric.

7. **Champion field.** The tracker has no "lead/champion" column on promises. If we want to record who's responsible, we'd add a `promises.champion` (text) column (migration), or a note in the summary/reference.
